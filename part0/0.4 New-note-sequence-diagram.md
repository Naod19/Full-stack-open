      participant browser
    participant server

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note

    Note right of server: Data is sent as the body and the Server access the data which comes inside the body  field using req.body

    Note right of browser: The Browser will later will use the header location to make GET request
	deactivate server

	browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/notes
	activate server
	server->>browser: HTML document
	deactivate server
